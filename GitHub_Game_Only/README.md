# The Missing Trophy

A small campus mystery made with HTML and CSS

The player reads three statements, checks the clues, types a guess, and reveals the solution

## Run the game

Open index.html in a browser and keep the files together

## Main features

Five connected pages
Blue and orange boxes
Evidence filters made with radio buttons and CSS
A guess field and an ending reveal
Desktop layout/ mobile(barely)
Keyboard focus and reduced motion support

The guesses are not saved or automatically checked
