PJAbout

The Missing Trophy is a short campus mystery made with HTML and CSS.

Project scope

This project is being completed individually. The player reads three statements, checks the evidence, and reveals the solution.

What the project uses

  • Five HTML pages with the same navigation and stylesheet
  • Flexbox for navigation and Grid for the page layouts
  • Radio buttons and CSS for evidence filters
  • A page link and the :target selector for the ending
  • Media queries for smaller screens

AI assistance

AI assistance helped prepare the planning materials, HTML, CSS, and presentation. The project includes a code guide for reviewing and explaining the final files.
